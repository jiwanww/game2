# 능력전선 0.7.1-beta.1 · 던전 사운드 / 앱 프로젝트

몬스터 출현·공격·처치 사운드와 스테이지 클리어 성공음을 추가했습니다. 클리어 후 `승리`를 3초간 표시하고 강화 선택 창으로 전환합니다. PC 화면 품질 설정은 그대로입니다.

Windows 실행 앱, 자동 업데이트 코드, Android/iOS 프로젝트와 모바일 터치 입력을 추가했습니다. 앱 제작·스토어 배포 상태와 실행법은 **APP-RELEASE-GUIDE.md**를 먼저 확인하세요. Windows 테스트 압축본은 업데이트 주소 미연결 상태이며 Android/iOS 스토어 등록도 아직 하지 않았습니다. `BUILD-WINDOWS-APP.bat`과 `BUILD-ANDROID-APP.bat`은 **제작자용 빌드 도구**로, 일반 플레이어가 실행하는 파일이 아닙니다.

## 새 모드: 던전 / 격리 프로토콜

기존 훈련, 사용자설정, 아트리움과 DISPLAY FIX A 설정을 유지하며 세 번째 모드를 추가했습니다.

- 혼자: `AbilityFront.html` 열기 → 던전 → 싱글 플레이 → 요원 선택 → 준비 완료. Node.js 없이 가능합니다.
- 협동: 기존 서버 실행 → 던전 → 멀티 플레이 → 방 만들기/참가 → 요원 선택 → 전원 준비. 최대 4명입니다. 친구는 같은 게임 주소와 방 코드를 사용합니다.
- V는 던전의 대시 키입니다. 대시에는 무적 시간이 없고, 3초마다 사용할 수 있습니다.
- 공통 버프 23종, 요원별 강화 8종씩 총 88종을 적용했습니다. 당초 15종 중 남은 7종씩은 후속 업데이트 대상이며 이번 선택지에 나오지 않습니다.
- 진행: 1~5 일반 전투 → 6에서 쉬움/중간/어려움 하나 → 7~11 고난도 → 미획득 전체 항목에서 보너스 2개 → 12 최종 보스. 1~5에서는 방 난이도 선택이 없습니다.
- 제한 시간 초과 또는 전원 사망 시 실패하고 이번 도전의 강화는 삭제됩니다. 방 사이 체력은 자동 완충되지 않습니다. 단, 스킬은 방 입장 시 준비 상태가 됩니다.
- 일반 몬스터 8종, 엘리트 3종, 3페이즈 보스 1종. 낙사 구멍·독성 지대·회전 레이저·축소 안전 구역·실제 충돌 지형을 추가했습니다.
- 해금 보상 선택 구조와 브라우저 로컬 기록이 있습니다. 베타에서는 요원 11명이 모두 열려 있습니다. 로그인 계정이나 서버 영구 저장·동기화는 아직 없습니다.

세부 수치와 던전 전용 조정, 현재 구현한 모든 강화 목록은 `DUNGEON-GUIDE.md`에 있습니다. 싱글에서는 Esc로 전투와 시간이 멈추지만 협동은 계속 진행됩니다.

새 ZIP을 별도 폴더에 전부 풀고, 이전 서버 창을 종료한 뒤 새 폴더에서 실행하세요. 시작 화면 상단에 0.7 BETA, 세 번째 카드에 던전 모드가 표시됩니다.

검증: 상태/규칙/스킬/협동 HTTP 연결/화면 DOM 계약 자동 테스트. 실제 브라우저 GPU 화면 비교, 여러 집 사이의 인터넷 품질과 20~30분 완주 밸런스는 별도 실플레이 검증이 필요합니다.

아래는 유지된 기존 모드 안내입니다. 던전에는 크레딧, 스파이크, 궁극기 구슬이 없습니다.

## 혼자 사용자설정 시작

START-WINDOWS.bat 실행 → 내 PC 주소 접속 → 사용자설정 → 맵·라운드·스킬 한도 선택 → 방 만들기 → 게임 시작 → 요원 선택·준비 완료. START-INTERNET.bat으로도 가능합니다.

혼자 시작하면 자동으로 혼자 연습 모드가 됩니다. 상대 팀이 없어도 전멸 승리로 종료되지 않으며, 매 라운드 공격 베이스에서 폭탄을 주워 설치하고 F로 직접 해체할 수 있습니다. 설정한 라운드 수와 시간 제한은 적용됩니다. 봇은 추가되지 않습니다. 2명 이상은 기존 공수 대전 규칙을 사용합니다.


첨부 사진에서 보인 거친 윤곽·누락된 그림자를 해결하기 위한 화면 수정판입니다. 첫 사진과의 실제 GPU 비교는 아직 수행하지 못했습니다.

- 시작 화면에 DISPLAY FIX A가 표시되는지 확인하세요. 없다면 다른 파일 또는 이전 서버에 접속한 것입니다.
- 게임 진입·화면 크기 변경 시 그림자를 켜고 렌더 배율을 최소 1.5로 다시 적용합니다. 자동 화질 축소 및 성능 우선 옵션은 없습니다.
- 훈련 중 H → 화면 복원으로 다시 적용할 수 있습니다. 같은 창에서 3D 버퍼 해상도·그림자·실제 AA 지원 여부를 확인할 수 있습니다.
- 그림자 켜짐으로 표시되어도 그림자가 보이지 않으면 설정창과 게임 화면을 함께 공유해 주세요.

## 이전 화면 설정 기록

화면 설정은 보관된 초기 0.2 코드와 비교해 적용했습니다. 렌더 배율 상한 1.5, 그림자 2048×2048, MSAA 켜짐, 부드러운 실시간 그림자, 노출 1.15, 시야각 78도입니다. 멀티도 하늘색 #91b8cb, 안개 거리 40~110을 사용합니다. 큰 맵에서는 먼 구간이 이전보다 안개에 빨리 가려집니다. 게임 규칙과 최근 두 요원 수정은 그대로입니다.


아트리움 추가판(0.6)의 렌더링·화질·멀티 동기화 설정을 사용합니다. 이후 성능 패치의 구조물 묶음 렌더링, 해상도 제한·자동 축소, FPS·응답시간 계측은 포함하지 않습니다. 변경 이력을 역적용해 재구성했습니다.

## 추가한 두 가지 수정

- 그린몬스터 궁극기: 하강 후 착지 판정이 풀려 충격파가 발생하지 않던 오류 수정. 야외·중앙 홀·낮은 천장 아래에서 반경 6.8m, 피해 50·기절 3초를 한 번 발생시킵니다.
- 헤라 영혼 흡수: 처치 위치에 구체 형태의 발광 영혼 구슬이 5초간 떠 있습니다. E로 흡수하면 0.7초간 구슬이 시전자에게 이동하고 양손을 당기는 모션을 재생합니다. 만료 후에는 새 처치로 유효한 구슬을 얻기 전까지 사용 불가하며, 구슬이 없을 때 E 횟수는 소모하지 않습니다. 기존 회복·피해 수치는 유지합니다.

기존 서버 종료 → 새 폴더에 전체 압축 해제 → START-INTERNET.bat 실행. 실제 브라우저 화면의 연출은 미검증입니다.

## 새 5대5 맵: 아트리움

사용자설정 → 맵에서 **아트리움 / ATRIUM**을 선택합니다. 스카이라인도 그대로 선택할 수 있습니다.

- 크기 128 × 144, 기본 요원 높이 1.8 유지. 기존 스카이라인과 같은 전체 크기입니다.
- 왼쪽 A / 중앙 MID / 오른쪽 B의 세 동선. 낮은 통로(층고 3.1m)와 중앙 홀(층고 12m), 설치 로비(층고 7m)가 대비됩니다.
- 중앙 홀의 양옆 4.2m 회랑으로 네 계단이 연결됩니다. 계단은 점프 없이 걸어 올라갈 수 있고 난간은 충돌·공격 차단 판정을 가집니다.
- 갈색 파괴 벽 두 개는 선택적 지름길입니다. 다른 경로는 파괴 없이 통과 가능하며 벽은 다음 라운드에 복구됩니다. 여닫는 문은 이번 버전에 포함하지 않았습니다.
- 겹치는 천장이 맵 미리보기·미니맵에서 통로를 가리지 않도록 지상 구조 위주로 표시합니다.
- 격자 경로 검사: 양 팀 중앙까지 각각 65m, 공격 베이스에서 A/B 각각 132m, 수비 베이스에서 A/B 각각 70m. 기본 속도 5.5 기준 중앙까지 약 11.8초. 이는 격자 경로 추정치이며 요원 이동 스킬·교전 시간은 제외합니다.
- 기존 요원 수정·크레딧·설치 폭탄·궁극기 구슬 시스템 유지. 실제 10인 플레이와 그래픽은 별도 플레이 테스트가 필요합니다.

## 다른 집의 친구와 시작하기 (Windows 64비트)

1. 새 ZIP을 별도 폴더에 **전체 압축 해제**합니다.
2. 방장만 **START-INTERNET.bat**을 더블클릭합니다. 방장 PC에는 Node.js 20 이상이 필요합니다.
3. 첫 실행 때 공식 Cloudflare 연결 프로그램을 다운로드하고 검증합니다. 잠시 기다리면 HTTPS 주소가 표시되고 브라우저가 열립니다.
4. **사용자설정 → 맵·라운드·스킬 제한 선택 → 방 만들기**.
5. 친구에게 실행 창의 **https://…trycloudflare.com 주소 + 방 코드 6자리**를 보내세요. 친구는 Chrome/Edge만 있으면 되며 Node.js나 게임 파일을 설치하지 않습니다.
6. 양 팀에 참가자가 들어오면 **게임 시작 → 요원 선택 → 모두 준비 완료**.
7. **화면 클릭 · 대전 복귀**로 마우스 시점과 효과음을 켭니다. 경기 내내 서버 창을 켜 두세요. 종료는 Ctrl+C입니다.

초대 주소는 실행할 때 바뀔 수 있습니다. localhost와 192.168.… 주소는 다른 집의 친구에게 보내면 안 됩니다. 주소가 안 만들어지면 실행 창의 오류를 확인하세요. 방장 PC의 인터넷에서 GitHub 다운로드와 Cloudflare 연결이 가능해야 합니다.

같은 공유기에서만 플레이하려면 기존 **START-WINDOWS.bat** 또는 **START-MAC.command**를 사용합니다. 인터넷 자동 실행기는 현재 Windows 64비트용입니다. 혼자 훈련할 때는 **AbilityFront.html**만 열면 됩니다.

새로고침 후에는 **이전 방 다시 참가**를 누르세요. 잠깐 연결이 끊기면 자동 재접속을 시도합니다. 오래 끊겨 탈락하면 다음 라운드부터 복귀합니다. 새 참가자는 대기실에서만 들어올 수 있습니다.

## 맵 크기와 구성

기존 테라스는 1대1, 분기점은 3대3으로 변경했고 기존 폴드는 제거했습니다.
새 5대5 스카이라인은 요원 높이를 1.8로 유지한 128 × 144 공간입니다. 요원 높이를 1로 두면 가로 약 71.1, 세로 80입니다.
A/B 사이트, 중앙 광장, 공격·수비 베이스, 고가 통로, 파괴 엄폐물, 이동 가능한 상자를 배치했습니다.

어센트의 정확한 실측 치수는 확인하지 못했습니다. 따라서 이 맵은 어센트와 동일 크기·구조를 복제한 맵이 아닙니다. 3갈래 전술 맵의 목표를 참고한 별도 설계입니다.
검증된 것은 현재 배치의 지상 경로 대칭입니다. 실제 요원별 승률 밸런스는 플레이 테스트가 더 필요합니다.

| 경로 | 지상 격자 경로 길이 | 기본 속도 5.5 기준 |
|---|---:|---:|
| 공격 베이스 → A / B | 양쪽 129 | 양쪽 약 23.5초 |
| 수비 베이스 → A / B | 양쪽 78 | 양쪽 약 14.2초 |
| A ↔ B | 122 | 약 22.2초 |

격자 측정은 1단위 직교 이동, 지상 보행 경로 기준입니다. 대각선 이동·점프·비행·이동 스킬을 사용하면 달라집니다.
지도 측정 명령: `node tests/map-metrics.mjs`.

## 설치 폭탄과 라운드

- 폭탄은 공격 베이스 바닥에 하나 생성됩니다. 공격팀이 위로 지나가면 습득합니다.
- 소지자만 사이트에서 F 4초 홀드로 설치합니다. 폭발 45초, 해체 F 7초, 절반 진행 저장.
- **4로 폭탄 선택 → G로 내려놓기**. 다른 공격팀원이 접근하면 습득합니다.
- 운반자가 탈락하면 그 자리에 폭탄을 떨어뜨립니다.
- 공격팀은 수비 전멸 또는 폭탄 폭발로 승리. 수비는 설치 전 공격 전멸, 제한 시간 만료, 설치 후 해체로 승리합니다.
- 설치 후 공격팀 전멸만으로는 라운드가 끝나지 않습니다.
- 정한 1~99 라운드를 진행하고 중간에 공수를 교대합니다. 준비 12초, 설치 제한 100초입니다.
- 사망 시 관통 가능한 잔해 원반과 요원-플레이어 이름 표시. 생존 팀원 시점으로 전환하며 좌/우클릭으로 관전 대상을 바꿉니다.
- 살아 있는 요원 위 이름은 제거했습니다. 아군 파랑 / 적 빨강 가장자리 발광을 적용하고 킬로그는 우측 상단에 2초 표시합니다.

## 크레딧: 5대5 + 스킬 횟수 제한일 때

전반·후반 시작 800, 최대 보유 9,000. 처치 +200, 설치 시 공격팀 전원 +300.
승리 +3,000. 패배 보상 1,900 / 연패 2,400 / 3연패 이상 2,900.
설치하지 못하고 생존한 공격팀, 폭발 후 생존한 패배 수비팀은 1,000 보상입니다.
구매는 준비 시간 B에서 진행합니다. 스킬·방어구 가격을 표시하고 보유 크레딧보다 비싸면 구매되지 않습니다.
미사용 구매 스킬은 다음 라운드에 남고 기본 제공 충전은 복원됩니다. 살아남은 플레이어는 남은 방어구를 유지합니다.
1대1·3대3 또는 스킬 무한에서는 기존 연습용 무한 크레딧을 유지합니다.

## 전투와 궁극기

직접 공격은 머리 1.5배 / 몸 1배 / 다리 0.75배. 광역·지속·잡기 피해는 특정 부위 배율 없이 적용합니다.
높이 3.5를 넘는 낙하는 초과 높이당 피해 12, 최대 100입니다. 스파이디·아크리터맨·또르는 낙하 피해가 없습니다.
처치·사망·설치·해체·구슬마다 궁극기 +1. 포인트는 라운드가 바뀌거나 죽어도 남습니다.
구슬은 매 라운드 통행 가능한 무작위 위치 2곳에 생성되며 F 2초 홀드로 획득합니다.

## 성능·입력 개선과 검증

서버에서 보이지 않는 입자 계산을 제거하고, 공격 판정에 필요한 물체만 행렬 갱신·교차 검사를 하도록 변경했습니다.
개미와 불길은 묶어서 렌더링합니다. HUD는 초당 10회 갱신하고 그림자는 1024, 기본 픽셀 비율은 1로 낮췄습니다.
동일한 52×52 공간의 10명 투사체 시나리오에서 틱당 약 6.9ms → 1.3ms를 관측했습니다. 이는 한 환경의 서버 측 샘플이며 실제 FPS·인터넷 지연 보장은 아닙니다.

Ctrl 단축키 기본 동작 억제와 전체화면 키보드 잠금을 추가했습니다. 브라우저가 지원하고 전체화면을 허용해야 예약 단축키까지 잠글 수 있습니다. 지원하지 않는 브라우저에서는 단축키 차단이 완전하지 않을 수 있습니다.
Ctrl 홀드+이동+점프+공격의 물리 값이 정상인지 자동 검증했습니다.

자동 테스트: `node --test tests/*.test.mjs`.
현재 47개 테스트로 11요원, 크레딧, 폭탄, 시간 복원, 관전과 HUD 상태 등을 확인했습니다.
DOM 계약 테스트는 실제 WebGL 화면 검사와 다릅니다. 이 환경에서 브라우저 다운로드가 실패해 실제 그래픽 출력·Windows Ctrl 조합 입력·새 버전의 외부 실기 대전은 아직 검증하지 못했습니다.
이 버전은 기능 테스트용 프로토타입이며 요원별 승률을 통한 최종 밸런스 검증은 남아 있습니다.

## 파일과 실행

- START-INTERNET.bat: 다른 집 친구와 접속할 때 방장이 실행. 실행 중인 구버전 서버를 닫고 새 폴더에서 실행하세요.
- START-WINDOWS.bat / START-MAC.command: 같은 공유기 안의 대전.
- AbilityFront.html: 단일 파일 훈련.
- index.html / src: 게임 코드. 옮기거나 삭제하지 마세요.
- server.mjs / simulation.mjs / round-system.mjs / internet.mjs: 서버·전투·라운드·외부 연결.
- tests: 개발 검증. tools/build.py: 훈련 HTML과 ZIP 재생성.
- runtime: 인터넷 실행기가 자동 생성하는 연결 도구 폴더.

외부 연결은 기존 Cloudflare 개발용 임시 링크 방식이며 실행 창을 닫으면 끝납니다.
